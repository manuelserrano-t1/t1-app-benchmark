# T1 App — Competitive Benchmark

Interactive competitive benchmark for the T1 App (Daily Operations Hub MVP) — develops §3.3 of
the project six-pager with field evidence.

- **Phase 1 (shipping vertical):** complete — 16 field tests over Envia.com, DrEnvio, DHL
  Express, FedEx Mobile and Skydropx, with screenshot evidence, per-app dossiers, findings
  (HZ-1..12), hypothesis verdicts and design recommendations.
- **Phase 2 (store & payments):** in progress — Shopify, Tiendanube, Mercado Libre, Mercado
  Pago, Clip, Amazon Seller and Treinta.

The site is a single self-contained `index.html` (all evidence embedded). Published via GitHub
Pages. Raw evidence archive and internal method docs live outside this repo.

Method: zero-cost protocol (payment-gate stops), single test device (Motorola Edge 60 / iPhone
15), same test data across apps, evidence-first evaluation.
